# Release notes

## Version 2.0

This release contains the complete experimental workflow used by SDN-MFA-V2: the independent authentication study, the policy/binding network matrix, and the end-to-end chained study.

The main additions are resumable PostgreSQL checkpoints, three managed Mininet topologies, paired and randomized comparison blocks, software-biometric ROC/FAR/FRR analysis, bilingual reports and publication figures. Access-control, availability and technical failures are recorded as separate outcomes.

The partial-mesh spoofing path keeps physical host links up while temporarily moving the tested IP/MAC identity. This avoids an STP reconvergence delay between consecutive tasks.

The experiment cohort is isolated by database flags and a reserved username prefix. No particular local username is required by the code.
